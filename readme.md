# Career Guidance

## Overview
A web application that helps students choose colleges in India and abroad based on eligibility, aptitude tests, and preferences.

## Features
- Student Signup/Login
- Career & Location Selection
- College List and Details
- Aptitude Test
- Admin Management of Colleges

## Technologies Used
- Frontend: HTML, CSS, JavaScript, React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Hosting: localhost

## Installation
1. Clone the repository
   git clone https://github.com/yourusername/career-guidance-webapp.git
2. Install dependencies
   npm install
3. Setup `.env` file with MongoDB URI and JWT_SECRET
4. frontend : npm start
   backend : nodemon server.js
5. Open frontend in browser

## Usage
1. Register as a student or admin
2. Students can select careers, take tests, and view recommended colleges
3. Admins can add, update, and remove colleges
